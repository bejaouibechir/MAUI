# 💥 **Labo 1 — Présenter une ContentPage sous Shell**

## 🎯 Objectif

* Créer une ContentPage.
* L'intégrer dans un Shell.
* Personnaliser l’icône, le titre, et la route.
* Montrer l'utilisation de `FlyoutItem` et des propriétés avancées.

---

# 🟢 **Étape 1 — Créer une ContentPage**

## ✅ HomePage.xaml

```xml
<?xml version="1.0" encoding="utf-8" ?>
<ContentPage xmlns="http://schemas.microsoft.com/dotnet/2021/maui"
             x:Class="MauiApp1.HomePage"
             Title="Accueil">

    <StackLayout Padding="20">
        <Label Text="Bienvenue sur la page d'accueil sous Shell"
               FontSize="22"
               HorizontalOptions="Center"/>
        <Button Text="Afficher une alerte" Clicked="OnAlertClicked" />
    </StackLayout>
</ContentPage>
```

---

## ✅ HomePage.xaml.cs

```csharp
namespace MauiApp1
{
    public partial class HomePage : ContentPage
    {
        public HomePage()
        {
            InitializeComponent();
        }

        private async void OnAlertClicked(object sender, EventArgs e)
        {
            await DisplayAlert("Info", "Vous avez cliqué sur le bouton !", "OK");
        }
    }
}
```

---

# 🟢 **Étape 2 — Créer le AppShell**

## ✅ AppShell.xaml

```xml
<?xml version="1.0" encoding="utf-8" ?>
<Shell xmlns="http://schemas.microsoft.com/dotnet/2021/maui"
       xmlns:x="http://schemas.microsoft.com/winfx/2009/xaml"
       xmlns:local="clr-namespace:MauiApp1"
       x:Class="MauiApp1.AppShell"
       Title="Mon Application">

    <!-- Définir un item dans le Flyout -->
    <FlyoutItem Title="Accueil" Icon="home.png" Route="home">
        <ShellContent ContentTemplate="{DataTemplate local:HomePage}" />
    </FlyoutItem>

</Shell>
```

---


# 🟢 **Étape 3 — App.xaml.cs**

```csharp
public partial class App : Application
{
    public App()
    {
        InitializeComponent();

        MainPage = new AppShell();
    }
}
```

# 💥 **Ajouter une ContentPage sous Shell — version 100 % C#**

## 🎯 Objectif

* Déclarer la page **en C# uniquement**.
* L’ajouter dans `AppShell` directement en C# (pas de XAML).
* Montrer quelques astuces pratiques.

---

## 🟢 **1️⃣ Créer la page HomePage en C#**

```csharp
namespace MauiApp1
{
    public class HomePage : ContentPage
    {
        public HomePage()
        {
            Title = "Accueil";

            var label = new Label
            {
                Text = "Page d'accueil en pur C# 🟢",
                FontSize = 22,
                HorizontalOptions = LayoutOptions.Center
            };

            var button = new Button
            {
                Text = "Cliquez-moi"
            };

            button.Clicked += async (s, e) =>
            {
                await DisplayAlert("Hello", "Vous avez cliqué !", "OK");
            };

            Content = new StackLayout
            {
                Padding = 20,
                Children = { label, button }
            };
        }
    }
}
```

---

## 🟢 **2️⃣ Définir la page content sous Shell en C#**

### ✅ AppShell.xaml.cs

```csharp
namespace MauiApp1
{
    public partial class AppShell : Shell
    {
        public AppShell()
        {
            InitializeComponent();

            // Créer le ShellContent en C#
            var homeContent = new ShellContent
            {
                Title = "Accueil",
                Icon = "home.png",
                ContentTemplate = new DataTemplate(typeof(HomePage)),
                Route = "HomePage"
            };

            var flyoutItem = new FlyoutItem
            {
                Title = "Menu principal",
                FlyoutDisplayOptions = FlyoutDisplayOptions.AsSingleItem,
                Items = { homeContent }
            };

            Items.Add(flyoutItem);

            // Astuce 1 : enregistrer route explicitement (utile pour GoToAsync)
            Routing.RegisterRoute("HomePage", typeof(HomePage));

            // Astuce 2 : définir la propriété CurrentItem pour afficher la page initiale
            CurrentItem = flyoutItem;
        }
    }
}
```

---

## 🟢 **3️⃣ App.xaml.cs**

```csharp
public partial class App : Application
{
    public App()
    {
        InitializeComponent();

        // Créer le ShellContent en C#
        var homeContent = new ShellContent
        {
            Title = "Accueil",
            Icon = "home.png",
            ContentTemplate = new DataTemplate(typeof(HomePage)),
            Route = "HomePage"
        };

        var shell = new AppShell();
        shell.Items.Add(homeContent);
        shell.CurrentItem = homeContent;

        MainPage = shell;

    }
}
```
