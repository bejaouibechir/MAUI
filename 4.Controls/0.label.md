# Exemple de propriétés du label

## 1️ FormattedText**

Permet d’avoir plusieurs styles dans un même Label.

```xml
<Label>
    <Label.FormattedText>
        <FormattedString>
            <Span Text="Bonjour " FontAttributes="Bold" FontSize="20" />
            <Span Text="MAUI" TextColor="DarkOrange" FontAttributes="Italic" />
            <Span Text=" !" FontSize="24" TextColor="Green"/>
        </FormattedString>
    </Label.FormattedText>
</Label>
```
---

## 2️ HorizontalTextAlignment**

Aligner le texte horizontalement dans son conteneur.

```xml
<Label Text="Texte aligné à droite"
       HorizontalTextAlignment="End"
       BackgroundColor="LightGray"/>
```

---

## 3️ LineBreakMode**

Gérer comment le texte coupe ou pas.

```xml
<Label Text="Ceci est un texte très long qui devrait normalement dépasser la largeur du label, mais on va forcer un ellipsis."
       LineBreakMode="TailTruncation"
       WidthRequest="200"
       BackgroundColor="LightBlue"/>
```

**Astuce** : Utiliser `HeadTruncation`, `MiddleTruncation` ou `WordWrap` pour comparer.

---

## 4️ LineHeight**

Changer la hauteur des lignes (utile pour paragraphes longs).

```xml
<Label Text="Ligne 1\nLigne 2\nLigne 3"
       LineHeight="2"
       BackgroundColor="Beige"/>
```

**Astuce** : Augmenter à 2 ou 3 pour créer un effet « espacé ».

---

## 5️ TextDecorations**

Appliquer souligné ou barré.

```xml
<Label Text="Texte souligné et barré"
       TextDecorations="Underline, Strikethrough"
       FontSize="18"/>
```

**Astuce** : Souligne un prix original pour une promo.

---

## 6️ TextTransform**

Changer la casse automatiquement.

```xml
<Label Text="Transformé en majuscules"
       TextTransform="Uppercase"/>
```

**Astuce** : Transformer dynamiquement du texte entré par l’utilisateur.

---

## 7️ TextType**

Afficher du texte brut ou HTML.

```xml
<Label Text="<b>Texte en gras</b> et normal"
       TextType="Html"/>
```

**Astuce** : Afficher un petit texte formaté reçu depuis une API HTML.

---

##  8️ VerticalTextAlignment**

Aligner verticalement dans un conteneur plus grand.

```xml
<Frame HeightRequest="100" BackgroundColor="LightGray">
    <Label Text="Texte centré verticalement"
           VerticalTextAlignment="Center"
           HorizontalTextAlignment="Center"/>
</Frame>
```

**Astuce** : Créer des badges ou étiquettes visuelles.
