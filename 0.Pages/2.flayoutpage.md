# 💥 **Lab — FlyoutPage**

## 🎯 Objectifs

* Créer un **menu latéral (flyout)** complet et élégant.
* Naviguer entre plusieurs ContentPages.
* Afficher dynamiquement une page de contenu selon la sélection.
* Gérer le header du menu, les items, et personnaliser l’apparence.

---

# 🗂 **Arborescence du scénario**

```
(FlyoutPage)
├── Menu (Flyout)
│   ├── AccueilPage
│   ├── ProfilPage
│   ├── ParametresPage
│   └── À propos
└── Detail (page principale)
```

---

## ✅ **1️⃣ FlyoutPage.xaml**

```xml
<?xml version="1.0" encoding="utf-8" ?>
<FlyoutPage xmlns="http://schemas.microsoft.com/dotnet/2021/maui"
            x:Class="MauiApp1.MyFlyoutPage"
            Title="Menu principal">
    <FlyoutPage.Flyout>
        <ContentPage Title="Menu" BackgroundColor="White">
            <StackLayout Padding="20" Spacing="15">
                <Label Text="🌟 Mon Application" FontSize="22" FontAttributes="Bold" />
                <Button Text="Accueil" Clicked="OnAccueilClicked"/>
                <Button Text="Profil" Clicked="OnProfilClicked"/>
                <Button Text="Paramètres" Clicked="OnParametresClicked"/>
                <Button Text="À propos" Clicked="OnAboutClicked"/>
            </StackLayout>
        </ContentPage>
    </FlyoutPage.Flyout>

    <FlyoutPage.Detail>
        <NavigationPage>
            <x:Arguments>
                <local:AccueilPage />
            </x:Arguments>
        </NavigationPage>
    </FlyoutPage.Detail>
</FlyoutPage>
```

---

## ✅ **2️⃣ FlyoutPage.xaml.cs**

```csharp
namespace MauiApp1
{
    public partial class MyFlyoutPage : FlyoutPage
    {
        public MyFlyoutPage()
        {
            InitializeComponent();
        }

        private void OnAccueilClicked(object sender, EventArgs e)
        {
            Detail = new NavigationPage(new AccueilPage())
            {
                BarBackgroundColor = Colors.DarkSlateBlue,
                BarTextColor = Colors.White
            };
            IsPresented = false; // Fermer le menu
        }

        private void OnProfilClicked(object sender, EventArgs e)
        {
            Detail = new NavigationPage(new ProfilPage())
            {
                BarBackgroundColor = Colors.DarkOliveGreen,
                BarTextColor = Colors.White
            };
            IsPresented = false;
        }

        private void OnParametresClicked(object sender, EventArgs e)
        {
            Detail = new NavigationPage(new ParametresPage())
            {
                BarBackgroundColor = Colors.Teal,
                BarTextColor = Colors.White
            };
            IsPresented = false;
        }

        private void OnAboutClicked(object sender, EventArgs e)
        {
            Detail = new NavigationPage(new AboutPage())
            {
                BarBackgroundColor = Colors.OrangeRed,
                BarTextColor = Colors.White
            };
            IsPresented = false;
        }
    }
}
```

# Substituer les boutons pas une ListView

✅ Excellente précision !
Tu veux un **exemple FlyoutPage avec ListView**, **mais avec les éléments (items) directement définis *en dur* dans le XAML**, comme dans la doc officielle (avec `<x:Array>`), et **sans les construire en C#**.

Voici la version **claire, complète et 100 % XAML**, directement prête.

---

# 💥 **Lab complet FlyoutPage — ListView avec items définis en XAML**

## 🎯 Objectifs

* Créer un FlyoutPage avec un menu utilisant `ListView`.
* Définir les items du menu directement dans le XAML.
* Navigation dynamique dans la zone detail vers 4 pages : Accueil, Profil, Paramètres, À propos.

---

# 🟢 **Étape 1 — Classe `FlyoutPageItem`**

```csharp
namespace MauiApp1
{
    public class FlyoutPageItem
    {
        public string Title { get; set; }
        public string IconSource { get; set; }
        public Type TargetType { get; set; }
    }
}
```

---

# 🟢 **Améliorations — FlyoutMenuPage.xaml**

```xml
<?xml version="1.0" encoding="utf-8" ?>
<ContentPage xmlns="http://schemas.microsoft.com/dotnet/2021/maui"
             xmlns:x="http://schemas.microsoft.com/winfx/2009/xaml"
             xmlns:local="clr-namespace:MauiApp1"
             x:Class="MauiApp1.FlyoutMenuPage"
             Title="Menu">

    <StackLayout>
        <Label Text="Menu principal"
               FontSize="24"
               FontAttributes="Bold"
               HorizontalOptions="Center"
               Margin="0,20,0,20"/>
        <ListView x:Name="ListViewMenu"
                  SeparatorVisibility="None">
            <ListView.ItemsSource>
                <x:Array Type="{x:Type local:FlyoutPageItem}">
                    <local:FlyoutPageItem Title="Accueil"
                                          IconSource="home.png"
                                          TargetType="{x:Type local:AccueilPage}" />
                    <local:FlyoutPageItem Title="Profil"
                                          IconSource="profile.png"
                                          TargetType="{x:Type local:ProfilPage}" />
                    <local:FlyoutPageItem Title="Paramètres"
                                          IconSource="settings.png"
                                          TargetType="{x:Type local:ParametresPage}" />
                    <local:FlyoutPageItem Title="À propos"
                                          IconSource="about.png"
                                          TargetType="{x:Type local:AProposPage}" />
                </x:Array>
            </ListView.ItemsSource>
            <ListView.ItemTemplate>
                <DataTemplate>
                    <ViewCell>
                        <Grid Padding="10" ColumnDefinitions="Auto, *">
                            <Image Source="{Binding IconSource}" WidthRequest="30" HeightRequest="30" VerticalOptions="Center"/>
                            <Label Text="{Binding Title}" FontSize="18" VerticalOptions="Center" Margin="10,0,0,0"/>
                        </Grid>
                    </ViewCell>
                </DataTemplate>
            </ListView.ItemTemplate>
        </ListView>
    </StackLayout>
</ContentPage>
```

# 🟢 **Étape 3 — FlyoutMainPage.xaml.cs**

```csharp
namespace MauiApp1
{
    public class FlyoutMainPage : FlyoutPage
    {
        FlyoutMenuPage menuPage;

        public FlyoutMainPage()
        {
            menuPage = new FlyoutMenuPage();
            Flyout = menuPage;
            Detail = new NavigationPage(new AccueilPage());

            menuPage.ListView.ItemSelected += OnMenuItemSelected;
        }

        private void OnMenuItemSelected(object sender, SelectedItemChangedEventArgs e)
        {
            if (e.SelectedItem is FlyoutPageItem item)
            {
                var page = (Page)Activator.CreateInstance(item.TargetType);
                Detail = new NavigationPage(page)
                {
                    BarBackgroundColor = Colors.DarkSlateBlue,
                    BarTextColor = Colors.White
                };

                menuPage.ListView.SelectedItem = null;
                IsPresented = false;
            }
        }
    }
}
```
