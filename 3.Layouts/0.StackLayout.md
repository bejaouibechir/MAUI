# 💡 **Lab — Maîtriser StackLayout en .NET MAUI**

---

## 🟢 **Étape 1 — Créer un projet**

1️⃣ Créez un nouveau projet MAUI (MAUI App) dans Visual Studio.
2️⃣ Ouvrez `MainPage.xaml`.

---
✅ **Objectif** : Voir le comportement vertical par défaut.

## 🟡 **Étape 2 — Premier StackLayout vertical simple**

```xml
<StackLayout>
    <Label Text="Item 1" FontSize="24" BackgroundColor="LightBlue" />
    <Label Text="Item 2" FontSize="24" BackgroundColor="LightGreen" />
    <Label Text="Item 3" FontSize="24" BackgroundColor="LightPink" />
</StackLayout>
```
---

✅ **Objectif** :

* Observer l’espace autour du layout (Margin).
* Observer l’espace interne (Padding).
* Observer l’espace entre les items (Spacing).

## 🟠 **Étape 3 — Ajouter Spacing, Margin et Padding**

```xml
<StackLayout Margin="20" Padding="15" Spacing="10" BackgroundColor="Beige">
    <Label Text="Item 1" FontSize="24" BackgroundColor="LightBlue" />
    <Label Text="Item 2" FontSize="24" BackgroundColor="LightGreen" />
    <Label Text="Item 3" FontSize="24" BackgroundColor="LightPink" />
</StackLayout>
```
---

✅ **Objectif** : Passer en disposition horizontale et observer la différence.

## 🟣 **Étape 4 — Jouer avec Orientation**

Sens verticial: 

```xml
<VerticalStackLayout Margin="20" Padding="10" Spacing="15" BackgroundColor="Beige">
    <Label Text="Item 1" FontSize="20" BackgroundColor="LightBlue" />
    <Label Text="Item 2" FontSize="20" BackgroundColor="LightGreen" />
    <Label Text="Item 3" FontSize="20" BackgroundColor="LightPink" />
</VerticalStackLayout>

```
Sens horizontal:

```xml
<HorizontalStackLayout Margin="20" Padding="10" Spacing="15" BackgroundColor="Beige">
    <Label Text="Item 1" FontSize="20" BackgroundColor="LightBlue" />
    <Label Text="Item 2" FontSize="20" BackgroundColor="LightGreen" />
    <Label Text="Item 3" FontSize="20" BackgroundColor="LightPink" />
</HorizontalStackLayout>

```

---

✅ **Objectif** :

* Comprendre comment chaque bouton se positionne horizontalement dans le StackLayout.
* Voir l’effet des options sur l’alignement.
* 
## 🔵 **Étape 5 — Utiliser HorizontalOptions et VerticalOptions**

```xml
<StackLayout BackgroundColor="LightGray"  WidthRequest="300"
             HorizontalOptions="Center"
             VerticalOptions="Center"
             Margin="20" Padding="10" Spacing="10">
    <Button Text="Start" HorizontalOptions="Start" />
    <Button Text="Center" HorizontalOptions="Center" />
    <Button Text="End" HorizontalOptions="End" />
    <Button Text="Fill" HorizontalOptions="Fill" />
</StackLayout>
```
---

✅ **Objectif** :

* Observer comment les labels occupent l’espace supplémentaire.
* Comprendre `StartAndExpand`, `CenterAndExpand`, `EndAndExpand`.
* 
## 🔶 **Étape 6 — Ajouter Expand**

```xml
<StackLayout BackgroundColor="LightBlue"
         VerticalOptions="FillAndExpand"
         HorizontalOptions="FillAndExpand"
         Margin="20" Padding="10" Spacing="10">
    <Label Text="Label 1" TextColor="White" BackgroundColor="Blue" HorizontalOptions="FillAndExpand" VerticalOptions="StartAndExpand" />
    <Label Text="Label 2" TextColor="White" BackgroundColor="Green" HorizontalOptions="FillAndExpand" VerticalOptions="CenterAndExpand" />
    <Label Text="Label 3" TextColor="White" BackgroundColor="Red" HorizontalOptions="FillAndExpand" VerticalOptions="EndAndExpand" />
</StackLayout>
</StackLayout>
```

---
