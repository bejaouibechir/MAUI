# 💥 **Lab 1 — Créer une ContentPage entièrement en C#**

## 🎯 Objectif

* Créer une ContentPage **sans XAML**, tout en C#
* Manipuler dynamiquement les éléments
* Ajouter des interactions astucieuses (par ex. color swap, affichage dynamique, gestion d’événements)

## 💡 Exemple complet

```csharp
using Microsoft.Maui.Controls;
using System;

namespace MauiApp1
{
    public class DynamicContentPage : ContentPage
    {
        public DynamicContentPage()
        {
            Title = "Page Dynamique C#";
            BackgroundColor = Colors.LightGray;

            var label = new Label
            {
                Text = "Bienvenue sur une ContentPage 100% C# 🎯",
                FontSize = 20,
                TextColor = Colors.DarkBlue,
                HorizontalOptions = LayoutOptions.Center,
                Margin = new Thickness(0, 30, 0, 20)
            };

            var entry = new Entry
            {
                Placeholder = "Tapez quelque chose...",
                WidthRequest = 250
            };

            var button = new Button
            {
                Text = "Valider et changer la couleur",
                BackgroundColor = Colors.SlateBlue,
                TextColor = Colors.White
            };

            var infoLabel = new Label
            {
                Text = "Aucune saisie pour le moment.",
                FontAttributes = FontAttributes.Italic,
                HorizontalOptions = LayoutOptions.Center
            };

            button.Clicked += (s, e) =>
            {
                if (!string.IsNullOrWhiteSpace(entry.Text))
                {
                    infoLabel.Text = $"Vous avez écrit : {entry.Text}";
                    this.BackgroundColor = new Color(Random.Shared.NextDouble(), Random.Shared.NextDouble(), Random.Shared.NextDouble());
                }
                else
                {
                    infoLabel.Text = "Merci d’entrer un texte d’abord.";
                }
            };

            Content = new StackLayout
            {
                Padding = 20,
                Children = { label, entry, button, infoLabel }
            };
        }
    }
}
```

### ✅ Points astucieux

* Utilisation dynamique d’événements
* Changement aléatoire de couleur pour montrer l’interaction avec la propriété `BackgroundColor`
* Contrôle du texte d’entrée pour afficher un message personnalisé

# 💥 **Lab 2 — Créer une ContentPage hybride XAML + C#**

## 🎯 Objectif

* Combiner XAML (définition structurelle) et code-behind C#
* Ajouter une logique dynamique côté C#

## 💡 Exemple complet

### Fichier **MyHybridPage.xaml**

```xml
<?xml version="1.0" encoding="utf-8" ?>
<ContentPage xmlns="http://schemas.microsoft.com/dotnet/2021/maui"
             xmlns:x="http://schemas.microsoft.com/winfx/2009/xaml"
             x:Class="MauiApp1.MyHybridPage"
             Title="Page Hybride XAML + C#"
             BackgroundColor="Beige">

    <StackLayout Padding="20">
        <Label x:Name="TitleLabel"
               Text="Page hybride 😎"
               FontSize="24"
               HorizontalOptions="Center" />

        <Button x:Name="ActionButton"
                Text="Cliquez pour changer"
                BackgroundColor="Teal"
                TextColor="White"
                Margin="0,20,0,0" />

        <Label x:Name="ResultLabel"
               Text="État initial"
               HorizontalOptions="Center" />
    </StackLayout>
</ContentPage>
```

### Fichier **MyHybridPage.xaml.cs**

```csharp
using Microsoft.Maui.Controls;
using System;

namespace MauiApp1
{
    public partial class MyHybridPage : ContentPage
    {
        private int _clickCount = 0;

        public MyHybridPage()
        {
            InitializeComponent();
            ActionButton.Clicked += OnActionButtonClicked;
        }

        private void OnActionButtonClicked(object sender, EventArgs e)
        {
            _clickCount++;
            ResultLabel.Text = $"Bouton cliqué {_clickCount} fois";

            // Petite astuce : animer la taille du label pour attirer l'attention
            TitleLabel.ScaleTo(1.2, 150, Easing.CubicInOut);
            TitleLabel.ScaleTo(1, 150, Easing.CubicInOut);
        }
    }
}
```

### ✅ Points astucieux

* Animation simple et fluide (`ScaleTo`) pour un effet visuel valorisant
* Compteur dynamique
* Interaction propre entre XAML et code-behind

Voici une version **complète, enrichie et concrète**, avec **un exemple pratique pour chaque propriété et membre**.

## 🎯 5️⃣ Événements `Appearing` & `Disappearing`

### ✅ Exemple

```csharp
public class LifecyclePage : ContentPage
{
    private Label _statusLabel;

    public LifecyclePage()
    {
        Title = "Lifecycle Demo";

        _statusLabel = new Label
        {
            Text = "État inconnu",
            HorizontalOptions = LayoutOptions.Center,
            VerticalOptions = LayoutOptions.Center
        };

        Content = _statusLabel;
    }

    protected override void OnAppearing()
    {
        base.OnAppearing();
        _statusLabel.Text = "La page vient d’apparaître 🚀";
    }

    protected override void OnDisappearing()
    {
        base.OnDisappearing();
        Console.WriteLine("La page est sur le point de disparaître");
    }
}
```

### 💡 Astuce

Idéal pour déclencher des appels API ou enregistrer des logs d'usage.

## 🎯 8️⃣ Méthode `OnBackButtonPressed()`

### ✅ Exemple

```csharp
public class ConfirmBackPage : ContentPage
{
    public ConfirmBackPage()
    {
        Title = "Confirmation Retour";
        Content = new Label
        {
            Text = "Appuyez sur Retour pour tester.",
            HorizontalOptions = LayoutOptions.Center,
            VerticalOptions = LayoutOptions.Center
        };
    }

    protected override bool OnBackButtonPressed()
    {
        MainThread.BeginInvokeOnMainThread(async () =>
        {
            bool answer = await DisplayAlert("Confirmation", "Voulez-vous vraiment quitter ?", "Oui", "Non");
            if (answer)
            {
                base.OnBackButtonPressed();
                Navigation.PopAsync();
            }
        });

        return true; // Empêche le retour immédiat
    }
}
```

### 💡 Astuce

Utile pour prévenir la perte de données ou demander confirmation avant de quitter.

## 🎯 9️⃣ Méthode `FindByName<T>()`

### ✅ Exemple

**XAML :**

```xml
<ContentPage xmlns="http://schemas.microsoft.com/dotnet/2021/maui"
             x:Class="MauiApp1.FindExamplePage">
    <StackLayout>
        <Label x:Name="MyDynamicLabel" Text="Label initial" FontSize="20"/>
        <Button Text="Changer texte" Clicked="OnChangeTextClicked"/>
    </StackLayout>
</ContentPage>
```

**Code-behind :**

```csharp
public partial class FindExamplePage : ContentPage
{
    public FindExamplePage()
    {
        InitializeComponent();
    }

    private void OnChangeTextClicked(object sender, EventArgs e)
    {
        var label = this.FindByName<Label>("MyDynamicLabel");
        label.Text = "Texte modifié via FindByName 🎯";
    }
}
```

### 💡 Astuce

Accéder facilement à un contrôle défini en XAML sans forcément l’injecter en tant que champ.
