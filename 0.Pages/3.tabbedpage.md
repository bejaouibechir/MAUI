# 💥 **Lab complet TabbedPage (style officiel)**

## 🎯 Objectifs

* Créer une TabbedPage entièrement en XAML.
* Définir plusieurs onglets (`ContentPage`) directement dans XAML.
* Personnaliser les titres et icônes.
* Exemple cohérent avec la structure officielle.

---

# 🟢 **Étape 1 — AccueilPage.xaml**

```xml
<?xml version="1.0" encoding="utf-8" ?>
<ContentPage xmlns="http://schemas.microsoft.com/dotnet/2021/maui"
             x:Class="MauiApp1.AccueilPage"
             Title="Accueil"
             IconImageSource="home.png">

    <StackLayout Padding="20">
        <Label Text="Bienvenue sur la page d'accueil 👋"
               FontSize="22"
               HorizontalOptions="Center"/>
    </StackLayout>
</ContentPage>
```

---

# 🟢 **AccueilPage.xaml.cs**

```csharp
namespace MauiApp1
{
    public partial class AccueilPage : ContentPage
    {
        public AccueilPage()
        {
            InitializeComponent();
        }
    }
}
```

# 🟢 **Étape 5 — TabbedMainPage.xaml**

```xml
<?xml version="1.0" encoding="utf-8" ?>
<TabbedPage xmlns="http://schemas.microsoft.com/dotnet/2021/maui"
            xmlns:x="http://schemas.microsoft.com/winfx/2009/xaml"
            xmlns:local="clr-namespace:MauiApp1"
            x:Class="MauiApp1.TabbedMainPage"
            BarBackgroundColor="DarkSlateBlue"
            BarTextColor="White">

    <local:AccueilPage />
    <local:ProfilPage />
    <local:ParametresPage />
    <local:AProposPage />
</TabbedPage>
```
